# 拾光成章 | 游戏策划作品

《拾光成章》是一款以高中三年为主题的横屏叙事解谜游戏。玩家通过观察场景、梳理线索和完成剧情拼图，逐步找回从入学到毕业的六段青春记忆。

本项目重点展示叙事解谜、关卡结构、内容配置、难度曲线、玩家引导与反馈设计等游戏策划能力。

## 项目概览

| 项目 | 内容 |
| --- | --- |
| 游戏类型 | 叙事解谜、场景调查、剧情拼图 |
| 目标体验 | 在轻度推理中获得发现感，在拼图复原中完成情绪回收 |
| 目标玩家 | 喜欢校园题材、剧情体验与轻度解谜的玩家 |
| 平台 | Windows、Android |
| 引擎 | Unity 2022.3 |
| 内容规模 | 6 个章节、18 条调查链、54 组调查节点、6 幅剧情拼图 |
| 当前状态 | 六章完整流程已实现，支持章节解锁、本地存档与重复体验 |

## 策划工作

- 确立“调查线索、收集碎片、复原记忆”的核心概念与玩法循环。
- 设计调查、提示、剧情拼图、章节解锁和重复体验等系统规则。
- 规划六章主题、难度递进与情绪曲线，完成 54 组调查节点及相关选项文本。
- 设计新手引导、状态反馈和横屏界面的信息层级，并将需求落实为可体验原型。
- 根据线索可读性、提示使用情况、完成时长和误操作等指标规划后续试玩验证。

## 设计定位

### 核心体验

游戏围绕“从细节中找回记忆”展开。场景调查负责建立事件与人物关系，剧情拼图负责将零散线索转化为完整画面，章节结尾再用短句完成情绪落点。玩家获得的不只是通关结果，而是亲手把一段往事重新拼完整的过程。

### 核心玩法循环

`阅读调查档案 → 判断调查位置 → 观察物件 → 选择合理行动 → 获得线索与碎片 → 完成剧情拼图 → 解锁下一段记忆`

调查与拼图承担不同职责：调查阶段提供推理和信息确认，拼图阶段提供操作反馈和叙事奖励。两者共同服务于“拾回记忆”的主题，避免玩法与剧情彼此割裂。

## 系统设计

### 调查解谜

- 每章包含 3 条调查链，每条调查链由 3 个前后关联的步骤组成。
- 每个调查节点包含物件描述、正确行动、两个干扰选项、错误反馈和剧情发现。
- 后续节点会引用先前获得的编号、日期、位置、笔迹或物件关系，形成可验证的推理链。
- 错误选择不扣除资源，玩家可以重新观察并调整判断，保持轻叙事游戏的节奏。

### 调查档案与提示

- 右侧调查档案以环境特征描述目标区域，提供方向但不直接公布答案。
- 提示分为“环境提示、关系提示、行动提示”三级，玩家可按需要逐步降低解谜难度。
- 已完成节点会更新链路状态，让玩家随时确认当前目标与调查进度。

### 剧情拼图

- 六章拼图数量依次为 4、6、9、12、16、20 块，操作负荷随流程逐步提升。
- 前两章只考查图像观察与空间对应，第三章起加入碎片旋转，控制规则学习节奏。
- 碎片靠近正确位置后自动吸附；位置正确但方向错误时提供明确反馈。
- 拼图使用互相配对的凸榫与凹口，并通过异形点击区域保证操作判定与视觉轮廓一致。

### 进度与重复体验

- 完成章节后解锁下一章，并记录本地进度。
- 已通过调查的章节可直接跳过解密进入拼图，也可以重新体验完整调查流程。
- 章节选择页展示当前解锁状态，兼顾首次流程与回看需求。

## 关卡与难度设计

| 章节 | 调查主题 | 拼图规模 | 玩法递进 | 剧情回收 |
| --- | --- | ---: | --- | --- |
| 开学第一天 | 通过光线、座位号和新课本确认位置 | 2×2 | 三阶段新手引导，无旋转 | 第一次自我介绍与相识 |
| 第一次月考 | 比对时间、考号与试卷信息 | 3×2 | 增加线索交叉验证，无旋转 | 成绩比预想更好 |
| 秋季运动会 | 根据广播、跑道与班旗复原接力顺序 | 3×3 | 首次加入碎片旋转 | 获得金牌，全班欢呼 |
| 雨天分班 | 沿雨水痕迹还原被打湿的留言 | 4×3 | 扩大拼图规模，强化顺序推理 | 雨廊中挥手告别 |
| 高三晚自习 | 利用有限光线复原错题与倒计时 | 4×4 | 多物件连续推理 | 月色下结伴回宿舍 |
| 毕业当天 | 用跨章节旧物确认照片背后的人 | 5×4 | 汇总前三年线索，完成最终挑战 | 全班毕业合影与致玩家来信 |

难度并非只通过增加拼图数量实现。调查内容从单一物件观察逐步过渡到信息比对、顺序复原和跨章节回忆；操作规则则在玩家熟悉拖拽与吸附后再加入旋转，使认知负荷和操作负荷分阶段增长。

## 引导与反馈设计

- 第一章采用“发现发光物件、根据观察推理、拖拽并自动吸附”的三阶段教学。
- 可调查物件、当前链路、碎片数量和拼图归位数量均提供持续状态反馈。
- 正确行动会立即给出剧情发现与碎片奖励；错误行动说明判断缺少的依据。
- 最终章每归位一块拼图，屏幕随机位置会出现一句校园回忆；完成后以“我们毕业了”收束，并进入致玩家来信。
- 鼠标与单指触控共用交互逻辑，界面按 1920×1080 设计并适配横屏安全区。

## 叙事与内容设计

六个章节按高中时间线排列：入学、月考、运动会、分班、晚自习、毕业。每章选择能够代表阶段变化的普通物件作为叙事载体，例如课本、试卷、号码布、留言、错题本与毕业照，让信息发现和情绪记忆来自同一组内容。

剧情拼图分别对应：

- 入学：第一次认识新朋友
- 月考：成绩比预想更好
- 运动会：获得金牌，全班欢呼
- 分班：雨廊中挥手告别
- 晚自习：月色下结伴回宿舍
- 毕业：全班毕业合影

通关后的致玩家来信不限定玩家所处的人生阶段，主题集中在珍惜当下、理解过去的选择，并继续向未来前进。

## 设计取舍

- **线索明确度与解谜空间：** 调查档案描述可观察的环境特征，不直接写出物件名称或坐标，保留玩家判断过程。
- **挑战与叙事节奏：** 错误选择不设置惩罚，三级提示由玩家主动调用，避免卡关打断情绪推进。
- **内容消耗与重复体验：** 首次体验保留完整调查流程，通关后允许跳过已完成的解密，降低重复操作成本。
- **规则复杂度与学习成本：** 前两章先建立拖拽、吸附和图像匹配认知，再加入旋转，不在开局同时教授全部规则。

## 后续迭代方向

- 通过试玩记录各调查节点的首次正确率、提示使用层级和完成时长，定位过于直白或缺少依据的线索。
- 对比不同拼图规模下的完成时间与误操作次数，继续调整吸附范围和旋转提示。
- 补充章节间的过渡演出与声音层次，加强调查结果、拼图画面和情绪回收之间的连续性。

## 运行方式

1. 在 Unity Hub 中添加本目录，使用 `2022.3.62f3c1` 打开。
2. 首次导入后，编辑器会自动创建 `Assets/Scenes/Main.unity` 并加入 Build Settings。
3. 打开 Main 场景，点击 Play。

如自动配置未触发，可使用菜单 `拾光成章/配置项目`。

## 构建说明

- Windows：菜单 `拾光成章/构建 Windows`
- Android：安装 Android Build Support、SDK/NDK Tools 与 OpenJDK 后，使用菜单 `拾光成章/构建 Android`
- 项目校验：菜单 `拾光成章/运行项目校验`

构建前会自动校验 Unity 版本、主场景、六关调查数据、拼图数量、六张 1920×1200 拼图原画与横屏设置；校验失败时会中止构建并提示具体原因。

## 主要文件

- `Assets/Scripts/LevelDefinition.cs`：六章关卡、调查链、选项与剧情文本配置
- `Assets/Scripts/MemoryPuzzleGame.cs`：核心流程、提示、进度、章节与 UI 状态
- `Assets/Scripts/PuzzlePieceView.cs`：碎片拖拽、选择、旋转与吸附
- `Assets/Scripts/JigsawPieceFactory.cs`：互锁拼图轮廓、透明点击区域与边缘描线
- `Assets/Scripts/ProceduralArt.cs`：场景和拼图画面的程序化插画回退
- `Assets/Editor/ProjectValidation.cs`：资源、关卡数据、场景和横屏设置校验
