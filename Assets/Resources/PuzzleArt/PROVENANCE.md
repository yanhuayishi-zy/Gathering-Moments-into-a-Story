# 插画来源与版本

- 当前版本：v4，2026-10-03。
- 用途：六章解密完成后的拼图奖励图。
- 生成方式：ImageGen CLI 图片编辑，模型 `gpt-image-2`；Base URL 由本机环境变量提供，文档不记录任何密钥。
- 编辑依据：以 v3 六章插画为叙事底稿，以通过检查的第一关 v4 为统一水彩、水粉和断续线条参考。
- 人工检查：逐图检查故事可读性、人物关系、正脸弱化、肢体、文字、水印、画幅与系列一致性后才替换 Unity 资源。
- 源文件：`output/imagegen/puzzle-memories-v4/`；v3 原图保留在 `output/imagegen/puzzle-memories-v3/` 作为可恢复备份。

六章主题依次为：第一次上台自我介绍、月考取得不错成绩、运动会夺得金牌、分班挥手告别、晚自习后结伴回宿舍、毕业合影。
